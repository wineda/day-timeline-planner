# Day Timeline Planner（Obsidian プラグイン）

1日のタイムスケジュールを、Google カレンダーの「日」表示のように **時間帯をクリック／ドラッグして組み立てられる** Obsidian プラグインです。

v2.0 から、タスクは **デイリーノート内の Markdown ブロック（見出し + 本文）** として保存されます。
「1タスク = ノート内の1ブロック」なので、タイムラインで組んだ予定の下にそのままメモ・議事録・チェックリストを書け、一日にすることを1枚の Markdown にまとめられます。プラグインを外してもデータはただの Markdown として残ります。

## できること

### タイムライン

- **日 / 3日 / 週 / 2週 / 月 表示** … 既定は週表示（日曜始まり・7日分を横に並べる）。タイムライン上部のツールバーの「日 / 3日 / 週 / 2週 / 月」でいつでも切替。曜日ヘッダーや月のマスの日付をクリックするとその日の日表示へ（週・3日・日表示で**日付そのもの**をクリックしたときは、その日の**日報**が開きます）。**3日表示は今日・明日・明後日**（今日が一番左）。3日表示に切り替えたときと日をまたいだときは、今日が表示範囲に入っていれば今日が左端に来るようそろえ直します（◀ ▶ や日付選択で別の日を見に行っているときはそのまま）
- **2週間表示（今週・来週の2段）** … 週表示のタイムラインを上下に2段重ね、上段に基準日の週、下段にその翌週を出します。列幅・文字の大きさ・予実の左右2レーンは週表示と同じなので、14列に詰めるより読みやすく、来週の予定もそのまま見渡せます。段ごとに「今週 8/30〜9/5」のような見出し（呼び名は今週・来週・先週・再来週。右端にその週の予実合計）と曜日ヘッダーが付き、スクロールしても段の上に残ります。縮尺は既定で**2段が1画面に収まる高さ**に自動で合わせ（⋮ メニューの「2段（今週・来週）を1画面に収める」。Ctrl＋スクロール / ピンチや 4時間 / 8時間 / 12時間 / 標準 を選ぶと外れ、選んだ縮尺で各段が伸びます）、現在時刻の線は今日がある段にだけ出ます。タスクは**上下の段をまたいでドラッグ**でき（来週の同じ時刻へ送るなら真下へ）、◀ ▶ は2週間ずつ動きます。下段の日を日付ピッカーや日報から選んでも段は入れ替わりません（基準日が2週間の外へ出たときだけ、その週が上段になります）。定期タスクの自動反映は週表示と同じく表示中の日（14日分）に行われます
- **月表示** … カレンダーのマスに各日のタスクを時刻順に並べます（タグの色つき・時刻なしは破線）。タスクをクリックで編集、空きをクリック / ＋ で追加、右クリックでメニュー。まだノートに入っていない将来の定期タスクは薄く表示（取り消した回は打ち消し線）
- **タイムライン表示** … 時間軸は既定で 7:00〜22:00（表示する時間帯・1時間の高さ・週の始まりは設定で変更可）
- **表示する時間の幅（ズーム）** … ツールバーの「表示」メニュー（4時間 / 8時間 / 12時間 / 標準）で、一度に見える時間の幅を切替（選択は記憶されます）。30分単位で作業する日は 4時間 にすると細かいタスクが見やすくなります。「標準」は設定の「1時間あたりの高さ」に従います
- **予定と実績（予実管理）** … タスクの「予定」とは別に、実際に作業した時間を「実績」として記録できます。編集ダイアログの「実績」欄（`10:05 - 11:20 / 13:00 - 13:30` のように複数区間可、コピーボタンで予定を転記）で入力し、ノートには `- 実績: …` 行として保存（相互反映）。ツールバーの「表示」メニューの「予定 / 予実 / 実績」で表示を切替 — 予実では各日の列を左右に分け、**左＝予定（枠）、右＝実績（塗り）**で並べます。日付ヘッダーには実績と差異「6.8 +0.8」（小数1桁の時間）を1行で表示（予定の時間は幅を取るので出しません。実績がまだ無い日は何も出ません。予定・実績の時:分の内訳はマウスを乗せると出ます）
- **実績の自動記録** … 実績が空のタスクを**完了にすると自動で実績を記録**（今日のタスクを作業の前後で完了にしたら「予定の開始 〜 今」、それ以外は予定どおり。設定でオフ可）。**同じ日の他タスクの実績と重なる時間帯は除いて記録する**ので、完了操作が遅れたり中断したりしても実績が二重になりません。完了時のポップアップに実績の確認・修正欄が付くので、その場で直せます
- **実績の計測（ストップウォッチ）** … タスクを右クリック →「実績の計測を開始」で計測を始め、ツールバーの ⏺ チップをクリック（またはメニューの「計測を終了して実績に記録」）で経過時間がそのタスクの実績に追記されます。中断・再開すれば複数区間になります。⏺ チップの右クリックで「記録せずにやめる」も選べます。計測状態は保存されるので Obsidian を再起動しても続きます
- **実績バーのドラッグ修正** … 予実／実績表示では、実績バーをドラッグして時間帯を移動、下端をドラッグして終了時刻を変更できます
- **プロジェクト（大きなタスク）** … 複数日にまたがる仕事を1つの**プロジェクトノート**（既定 `Timeline/Projects/<名前>.md`）にまとめ、日々のタスクをそこへ結びつけられます。編集ダイアログの「プロジェクト」欄で選択・新規作成でき、ノートには `- プロジェクト: [[Timeline/Projects/環境構築]]` 行として保存（相互反映）。タイムラインのブロックに「▸ プロジェクト名」バッジが出て、クリックでノートが開きます。Wikilink なので **Obsidian のバックリンクでプロジェクトノートから全作業履歴が見えます**。メモや工程はプロジェクトノートに書けば1箇所に集まります
- **プロジェクトパネル** … サイドバーの「プロジェクト」タブに**進行中の**プロジェクトの一覧を表示（`環境構築 3/5`。予実の合計は行が見づらくなるため出さず、件数にマウスを乗せると表示。プロジェクトノートのタスク一覧・予実レポートでも見られます）。展開すると結びついたタスクが日付順に並び（**本日のタスクは「本日」（青）、日付未定のタスクは「未定」（アクセント色）、時刻未定のタスクは日付がオレンジの枠バッジ**で見分けられます。時刻未定＝持ち越し・再スケジュール待ちの遅れているタスクです）、日付ありのタスクは**クリックでその日へジャンプし、タイムラインの対応するブロックをアクセント色の輪で強調**（画面外なら見える位置までスクロールし、輪が2回またたきます。クリックした行にも印が付くので、パネルの行とタイムラインのブロックの対応が一目で追えます。別のタスクを選ぶか、タイムラインにフォーカスがある状態で Esc を押すと解除）、「未定」のタスクは**クリックで編集・タイムラインへドラッグで日時を割り当て**、チェックで完了切替、右クリックでメニュー。**行をタイムラインへドラッグするとそのプロジェクトの子タスクを作成**。ヘッダーの ⋮ メニューの「すべてのプロジェクトを展開 / 閉じる」（またはコマンド「プロジェクトのツリーをすべて展開 / 閉じる」）で**全プロジェクトのツリーを一気に展開 / 閉じられます**。同じ ⋮ メニューの「完了済みの子タスクを隠す」で**完了済み（持ち越し済みを含む）の子タスクを非表示**にできます（設定「プロジェクトの完了済みタスクを隠す」でも切替可）。行の右クリックメニューに**ノートを開く・タスクを追加・完了にする・グループの変更**がまとまっています（行に操作アイコンは出しません）。「このプロジェクトのタスクを追加」は**日付を決めずに「とりあえず登録」**します（実体は Inbox のノートに入りますが、パネル上はプロジェクトの子タスクに「未定」として並びます。ダイアログで時刻を入れた場合だけ表示中の日に入ります）。パネルは設定でオフにできます
- **プロジェクトパネルのメニュー（⋮）** … ヘッダーに機能のアイコンを並べる代わりに、右端の ⋮ （ケバブメニュー）1つにまとめています。「新しいプロジェクトを作成…」「すべてのプロジェクトを展開 / 閉じる」「グループの見出しを出さずフラットに一覧 / グループごとのツリーで表示」「完了済みの子タスクを隠す / 表示する」「全プロジェクトノートのタスク一覧を更新」を選べます（切り替え式の項目は、いま押すとどうなるかが項目名とアイコンに出ます）。どれも今までどおりコマンドパレットや設定からも操作できます
- **プロジェクトの新規作成（テンプレートから）** … プロジェクトパネルのヘッダーの ⋮ メニューの「新しいプロジェクトを作成…」（またはコマンド「新しいプロジェクトを作成」）で、名前とグループを入れてプロジェクトを作成できます。設定「プロジェクトのテンプレート」でテンプレートノートを指定しておくと、その内容から作成（`{{name}}` はプロジェクト名、`{{date}}`・`{{time}}`・`{{group}}` も置換。設定の「テンプレートを作成」ボタンでサンプルを書き出して編集できます）。完了チェックのメタ行（`- [ ] ^id`）はテンプレートに無くても作成時に自動で入ります。タスクの編集ダイアログの「プロジェクト」欄の「＋ 新規作成…」も同じテンプレートを使います。作成後はプロジェクトノートが開くので、そのまま書き込めます
- **プロジェクト自身の期日・チケット・ドキュメント** … 子のタスクに持たせられるもの（チケット・日付・本文のリンク）と同じ感覚で、親のプロジェクトノート自身にも `- 期日: 2026-09-15`・`- チケット: redmine#65130`・`- ドキュメント: [[設計書]] https://…` の行で持たせられます（テンプレートのサンプルには空の行が入っています。ドキュメント行は複数書け、1行に複数リンクも可）。パネルのプロジェクト行に**期日**（過ぎたら赤）と**チケット**のバッジ（クリックでブラウザで開く）が出て、ツリーを展開すると**ドキュメントのチップ**が子タスクの上に並びます（クリックで開く。行の右クリックメニューからも開けます）
- **プロジェクトのグループ** … プロジェクトをグループ分けして、パネルのツリーをグループごとに区切って表示できます。割り当てはパネルのプロジェクト行の**右クリック**（既存グループへ移動・新しいグループへ…・グループを外す）から。実体はプロジェクトノートの frontmatter（`group: 仕事`）なので手書きでも変えられ、リネームしてもグループはノートに付いて回ります。グループ見出しのクリックでグループごと開閉でき（「すべて展開」は畳んだグループも開きます）、グループなしのプロジェクトは「未分類」として末尾に並びます。ツリーでは階層をひと目で見分けられるよう、**グループ見出しにはフォルダ（`folder`）の既定アイコン**が付きます（設定「グループの既定のアイコン」で変更でき、Lucide のアイコン名か絵文字を指定。空欄でアイコンなし）。プロジェクト行にはアイコンを出しません（行が見にくくなるため）。グループの表示順は設定「プロジェクトのグループ」で管理でき、特定のグループだけ別のアイコンにしたいときは一覧のアイコン欄で既定を上書きできます（右クリックメニューにも表示。載っていないグループは名前順で後ろ）。どのプロジェクトにもグループが無ければ、今までどおりのフラットな一覧のままです
- **プロジェクトのフラット表示** … グループ分けで階層が一段深くなって見づらいときは、パネルの ⋮ メニューの「グループの見出しを出さずフラットに一覧」（コマンド「プロジェクト一覧のフラット表示（グループの見出しなし）を切り替える」・設定「プロジェクトをフラットな一覧で表示」でも可）で、**グループの見出しを出さずプロジェクトだけを一覧**できます。並びは**グループ順のまま**平らにするので、同じグループのプロジェクトは隣り合って並びます（ツリーと同じ約束: 設定の表示順 → 名前順 → 未分類は末尾。各グループの中は名前順）。どのグループかを確かめたいときはツリー表示に戻してください。選択は記憶され、もう一度押すとツリーに戻ります
- **プロジェクトの完了** … パネルの行の右クリックメニュー「プロジェクトを完了にする」でプロジェクトを完了にできます（未完了のタスクが残っていれば確認あり）。完了したプロジェクトは**パネルにも編集ダイアログ・定期タスクの選択肢にも出ません**（ノートと過去タスクのリンク・バッジはそのまま）。実体はプロジェクトノート先頭のチェック（`- [x] ^id`）なので、チェックを外せば進行中に戻ります。子タスクが全部閉じたときにも完了を提案します。**手作りのノート（チェック行が無いもの）でも大丈夫**：完了にしたとき、見出しの直下にチェック行を自動で書き足します（ID はその場で採番。プロジェクトへのリンクはノート単位なので、この ID を参照するものはありません）
- **プロジェクト＝ボス戦（モンスターと HP バー）** … プロジェクトパネルの各行の左に**ドット絵のモンスター**、右に **HP バー**が出ます。HP は**子タスクの予定時間の合計**（時刻の無いタスクは設定「既定の長さ」で数える）で、**ステップをチェックすると小さな一撃、タスクを完了にすると大きな一撃**（残りの予定時間ぶん）が入り、HP が減ります。編集ダイアログでは自動保存のたびではなく**閉じたときに、開いてからの差分をまとめて**演出します（ステップを 4 つチェックして閉じれば 4 連撃、そのまま完了にすれば連撃のあとに大の一撃）。**最後のタスクを完了すると討伐**：大の一撃のあとモンスターがふるえて倒れ、「討伐」の判と総工数（実績の合計。無ければ予定）が出ます（そのあと今までどおりプロジェクトの完了を提案）。モンスターは 30 種で、予定時間の合計が 10 時間未満なら**雑魚（★・16 ドット）**、10〜40 時間で**中級（★★・24 ドット）**、40 時間以上で**ボス（★★★・32 ドット）**と、大きい仕事ほど大きく強そうな姿になります（閾値は設定で変更可。タスクを足すと途中でランクが上がることもあります）。**難易度はプロジェクトの作成ダイアログで選べます**（おまかせ / 雑魚 / 中級 / ボス。選ぶとその姿がプレビューに出て、「別の姿にする」で同じランクの別の1体に替えられます。決めた内容はプロジェクトノートに `- 難易度: ボス`・`- モンスター: ドラゴン` の行として保存され、以後はタスクを足しても姿が変わりません。あとから変えるときはプロジェクト行の右クリック「難易度を変更…」か、ノートの行を手で書き換えます。テンプレートのサンプルにも空の行が入ります）。おまかせのときは**予定時間の合計**から自動で決まり、どの1体になるかはプロジェクト名で決まります（プロジェクトノートに `- モンスター: ドラゴン` の行を書けば固定できます（雑魚: スライム・ゴブリン・コボルト・スケルトン・ゾンビ・バット・ウルフ・マンドラゴラ・ミミック・インプ / 中級: オーク・オーガ・トロール・ガーゴイル・ハーピー・ケンタウロス・コカトリス・ワーウルフ・ゴーレム・ミノタウロス / ボス: グリフォン・キメラ・バジリスク・ワイバーン・ヒドラ・クラーケン・ヴァンパイアロード・リッチ・デーモンロード・ドラゴン）。HP が半分を切ると汗をかいて口が波打ち、2 割を切ると目が「><」になります。演出は行の上に重ねて出すので、パネルの別のタブを見ているときや狭い画面でタイムラインを見ているときはビューの右下に出ます。効果音（Web Audio の短い打撃音）は設定「ボス戦の効果音」で切れ、機能ごと要らなければ設定「プロジェクトをボス戦として表示」でオフにできます（テーブル表示ではモンスターの小さなアイコンだけ名前の前に出ます）
- **プロジェクト一覧の絞り込み（すべて / 本日）** … 一覧の上の切替で、**進行中のプロジェクトをすべて**出すか、**今日のタスクがあるプロジェクトだけ**に絞るかを選べます（件数付き。よく使うので ⋮ メニューではなく一覧の上に出しています。選択は記憶され、コマンド「プロジェクト一覧の絞り込み（すべて / 本日タスクあり）を切り替える」でも切り替えられます）
- **ペット（対応中のプロジェクトのモンスター）** … いま対応中のタスクが結びついているプロジェクトのモンスターを、画面に浮かべて出します。対象は**計測中のタスク → 現在時刻にかかっているタスク → 次のタスク → 時刻を過ぎて残っているタスク → 時刻未定**の順（プロジェクトの無いタスクは飛ばします。該当が無ければ出ません）。**ドラッグで画面の好きな位置へ**動かせ（位置は記憶されます。既定は右下）、マウスを乗せると「いま: タスク名 / プロジェクト名 · HP」の吹き出し、**クリックでそのタスクを編集**、右クリックでプロジェクトノートを開く・隠す。ボス戦の一撃・討伐の演出に合わせて、同じプロジェクトならペットものけぞります。設定「対応中のプロジェクトのモンスターを画面に出す（ペット）」でオン／オフ（ボス戦がオフのときは出ません）
- **プロジェクトノートのタスク一覧** … プロジェクトノートを（バッジ・パネル・ダイアログから）開くと、ノート内の「## タスク」セクション（`<!-- dt-project-tasks -->` マーカー内）を自動更新します。完了・日付・タスク（ブロックへのリンク付き）・予定・実績・合計の表なので、ノート単体でも全体が見えます。コマンド「プロジェクトノートのタスク一覧を更新（すべて）」やパネルの ⋮ メニューで一括更新も可能。マーカーの外は書き換えないので、共有メモは自由に書けます
- **プロジェクトの完了提案** … 子タスクを完了にしたとき、そのプロジェクトの子が全部完了していたら「プロジェクトも完了にしますか？」と確認し、プロジェクトノートのメタ行を `- [x]` にします
- **定期タスクとプロジェクト** … 定期タスクのルールにプロジェクトを設定でき、自動で入るタスクが最初からそのプロジェクトに結びつきます（タスクの右クリック「定期タスクとして登録…」ではタスクのプロジェクトを引き継ぎ）
- **サイドバーはタブで切り替え** … Inbox・プロジェクト・再スケジュールを縦に全部並べると長くなるので、パネルの上部のタブで**1つずつ切り替えて表示**します（選んだタブは記憶されます）。タブが1つしか無いときはタブは出ません。再スケジュールのタブはタスクがあるときだけ現れ、**過去に取り残された時刻なしタスクがあると赤い点**が付くので、別のタブを見ていても気付けます（件数はタブのツールチップにも表示）。ヘッダーのボタン（Inbox の ＋・ノートを開く / プロジェクトの ⋮ メニュー / 再スケジュールの ＋）は表示中のタブのものに切り替わります
- **サイドバーの幅** … Inbox・プロジェクトのパネルは右端をドラッグして幅を変えられます（160〜480px。記憶されます）
- **本日のサマリー** … サイドバーのタブの下に、今日の進み具合をどのタブを見ていても常に表示します。**消化タスク / 全タスク数**と**予定時間ベースの達成率**（完了したタスクの予定時間 / 今日の予定時間）の2本のバー（**タスクごとに縦線で区切り**、件数は等分・時間は予定の長さに比例。完了したぶんを左に寄せて塗るので、残りの区切りで大きいタスクがいくつ残っているかも分かります。区切りにマウスを乗せるとタスク名）、**あと N 件・残りの予定時間・実績の合計**、**いま / 次にやる1件**（チェックで完了、▶ で実績の計測を開始、クリックで編集、右クリックでメニュー）、**連続達成日数**（達成率が閾値・既定 80% 以上の日の連続。タスクの無い日は数えず、今日はまだ途中なので途切れません）と**今週 7 日ぶんの達成率の棒グラフ**、**結果・ふりかえりの未記入件数**を並べます。持ち越し `[>]` にしたタスクは「今日やる分」から外れます。見出しのクリックで1行に畳めます。設定「本日のサマリーを表示」「連続達成に数える達成率」で調整できます（タスクブロック形式のときだけ）
- **狭い画面（スマホなど）ではタイムライン ⇄ パネルを切り替え** … ビューの幅が狭いとき（約500px未満。Android などモバイルの縦画面）は、サイドバーとタイムラインを並べず**片方だけを全面に表示**します。ツールバーに現れる切替セグメント（タイムライン 🕐 とツリー ≡ の2つのアイコンが並び、表示中の面がアクセント色の背景で強調される。パネル表示中はパネルのヘッダーに同じセグメントが出ます）でいつでも行き来でき、コマンド「タイムライン / パネルを切り替える（狭い画面）」でも切り替えられます。パネルで日付ありの子タスクをタップするとその日のタイムラインへ自動で切り替わります。画面を広げれば（横向きにすれば）今までどおり並んで表示されます
- **残件の持ち越し** … 右クリック「**翌日へ持ち越す（記録を残す）**」で、タスクを移動せずに残件を翌日へ送れます。今日のブロックはチェックが `[>]`（持ち越し）になってその日の記録（実績・ステップ・本文）ごと残り、翌日に続きのブロック（タイトル・完了条件・プロジェクト・チケット・**未チェックのステップだけ**を引き継ぎ）が未スケジュールで作られます。両者は `- 持ち越し元/先: [[...]]` の Wikilink で鎖になり、バーの「◀ 前日から / ▶ 持ち越し先」バッジで行き来できます。「Inbox へ持ち越す」も選べます。**「当日内で続きを作る（記録を残す）」**を選ぶと、1回目が終わらず同じ日にもう一度取り組むときの続きのブロックを**同じ日のノート**に作ります（未スケジュールなので「再スケジュール」タブに並び、タイムラインへドラッグして2回目の時刻を決めます。バッジは「◀ 前回から / ▶ 続き（当日）」）。`[>]` のタスクはグレー表示で、完了数には数えません（プロジェクトの完了提案では「閉じた記録」として扱います）。本日のサマリーでは `[>]` のブロックの**実績とチェック済みのステップ**はその日にこなした分として数え、未チェックのステップは続きのブロック側で数えます。**持ち越し先（鎖の末端）のタスクが完了すると、引き継ぎ前の `[>]` のブロックもプロジェクトパネルとプロジェクトノートのタスク一覧では完了済みとして表示**します（打ち消し線・チェック済み・件数にも数える。ノートの一覧では `✅▶`）。戻すときは持ち越し先のほうを未完了にしてください
- **週の予実合計** … 3日・週・2週表示ではツールバーの日付の隣に表示範囲の合計（「週: 予 32:00・実 33:15（+1:15）」。2週表示は「2週: …」で、週ごとの合計は各段の見出しの右端）を表示。日ごとの合計は日付ヘッダーに出ます
- **日報（日付ヘッダーの日付をクリック）** … 週・3日・日表示の**日付（「木 3」）をクリック**すると、**設定「日報のフォルダ」（既定 `daily`。下の階層も含む）にあるその日の日報ノート**（ファイル名に `YYYY-MM-DD` を含む `.md`。AI などが書き出したもの）をポップアップでそのまま描画します（フロントマターは省き、ノート内のリンクはポップアップを閉じて開きます）。**左右にスワイプ（◀ ▶ ボタン・← → キーでも）すると前後の日の日報に移れます**（見出しの日付が今日なら「今日」のバッジ）。「ノートで開く」でその日報をタブで開き、「コピー」で本文を Markdown のままクリップボードへ。日報がまだ無い日は案内を出し、「タスクの集計を見る」でプラグインが集計した予定・実績・差異、タスクの一覧（時間・予実・チケット・プロジェクト・タグ）、結果／ふりかえりなどの記録、相手待ち、残っているタスク、プロジェクト別・タグ別・チケット別の集計を代わりに見られます（タスクの行をクリックするとその日へジャンプしてタイムラインの該当ブロックを強調。「集計をノートに書き出す」で `<フォルダ>/Reports/日報 YYYY-MM-DD.md` に書き出して開きます。コマンド「日報を見る（表示中の日）」「日報（タスクの集計）をノートに書き出す（表示中の日）」でも同じことができます）。**日付以外のヘッダー**をクリックしたときは今までどおりその日の日表示に切り替わります。**スマホ・タブレットでも同じように使えます**（タップしたタスクへ移動するときはタイムラインの面に自動で切り替わります。「コピー」はモバイルの WebView でも動くようフォールバックを入れています）。スマホ・タブレットでは、このプラグインのポップアップ（日報・タスクの編集など）は TickTick の詳細シートのように**下から出るシート**で、画面の上端まで伸ばさず高さを画面の 78% までに留めます（上に元の画面が少し見えます）。
- **予実レポート** … コマンド「予実レポートを作成（表示中の週）」で、その週の日別・タスク別／プロジェクト別／タグ別／チケット別の予定・実績・差異の表を Markdown ノート（`<フォルダ>/Reports/予実レポート YYYY-MM-DD.md`）に書き出して開きます。チケットはリンク付きなので、そのまま工数報告の元データにできます
- **タグで色分け** … タスクに書いた `#タグ` に応じてブロックの色を変えられます（設定「タグの色」）。タイムライン上ではタグの文字は出さず、色だけで示します
- **完了条件** … 編集画面の「完了条件」欄がノートの `- 完了条件: …` 行と相互に反映
- **ステップ** … タスクを小さく分けたチェックリスト。編集画面でチェック・追加・削除・**ドラッグで並べ替え**でき、ノートの `- [ ] …` 行と相互に反映
- **メンバー（他の人の予定）** … 設定でメンバー（名前・色）を登録すると、その人の予定を**別フォルダのノート**（`Timeline/Members/<名前>/YYYY-MM-DD.md`）に保存しつつ、自分のカレンダーに重ねて表示（グレー背景＋左端がその人の色）。ツールバーの「表示」メニューで人ごとに表示/非表示、編集ダイアログの「誰の予定か」で持ち主を選択・変更
- **チケット連携** … Redmine / Gitea / Backlog などのチケット番号をタスクに付けられます。タイムラインのブロックに `#65130` バッジが表示され、クリックでブラウザで開きます
- **記録 / 作業メモのタブ** … 編集画面は、AIが読む欄（結果・残・原因・判断・他者・回答・状態・Owner・期限・完了条件・次アクション・ふりかえり）を「記録」タブに、自分用の欄（ステップ・備考・リマインド）を「作業メモ」タブに分けています。作業メモのタブにはステップの消化（2/4）と備考の有無がバッジで出ます
- **備考** … 自由なメモ（Markdown・複数行）。ノートのブロック本文と相互に反映。10行を超えたときと、パスワード・トークンらしき文字列があるときは注意が出ます
- **結果とふりかえり** … 「何がどこまで終わったか（結果）」と「次はどう改善するか（ふりかえり）」を残す欄。**完了にしたとき、選んだタグで必須の欄（結果。#障害 なら原因・判断、#管理/質問 なら回答）が空なら、その欄だけを聞くポップアップが出ます**（15分以上なら、ふりかえりが空でも出ます。実績の確認・修正も同じ場所で。チェック済みのステップを結果の下書きにするボタン付き）。ノートの `- 結果: …` `- ふりかえり: …` 行と相互に反映され、日報・週報の元データになります
- **残ステップの確認** … 未チェックのステップが残るタスクを完了にしようとすると、**「残: に記録して完了 / 翌日へ持ち越す / 当日内で続きを作る / そのまま完了」を確認**します。残件を `- 残: …` として書いておけば、完了扱いのまま埋もれません
- **削除の記録** … タスクを削除すると `<フォルダ>/Log.md` に日時・タイトル・元のノートを1行で記録（設定でオフ可）。消えたタスクが「意図した削除」だったか後から確かめられます
- **クリックで追加** … 空いている時間をクリック → 既定の長さのタスクを作成
- **ドラッグで範囲を指定して追加** … 空いている時間をドラッグ → その範囲でタスクを作成
- **タスクをドラッグして移動**（週表示では別の日の列へドラッグして日付も移動）、**下端をドラッグして長さを変更**
- **クリックで編集**（タイトル・開始・終了・完了）、右クリックメニューで完了／削除／翌日へ送るなど
- 重なったタスクは横に並べて表示。**現在時刻の赤いライン**は TickTick 風に、表示中の全列をまたぐ細い線を引き、今日の列だけ太い線と●で強調。左の時刻の目盛りには現在時刻（`17:58`）が赤いラベルで出ます（重なる `18:00` の目盛りは隠れます。今日が表示範囲にあるときだけ）
- タイムラインの真上のツールバーの ◀ ▶ / 「今日」/ 日付クリックでカレンダーから選択（← → キーでも移動。3日表示は3日、週表示は1週間、月表示は1か月ずつ）
- **モバイル（スマホ・タブレット）での操作** … Google カレンダーの操作感に合わせています
  - **横スワイプ**で前後の日（3日・週・月表示ではその単位）へ移動。縦スワイプはスクロール。スワイプで誤ってタスクが作られることはありません
  - **空き時間をタップ** → その枠に「＋ 時刻」チップが出て、**もう一度タップで作成ダイアログ**。**長押し → そのままドラッグ**で範囲を決めて作成もできます
  - **タスクはタップで編集**、**長押しで持ち上げてからドラッグ**で移動（週・3日表示では別の日へも）。下端のつまみを長押し → ドラッグで長さを変更
  - **長押しして動かさずに離すとメニュー**（完了・削除・持ち越し・実績の計測など、右クリック相当）
  - 月表示はマスをタップするとその日の日表示を開きます（タスクの追加はマスの＋から）
  - 右下の**＋ボタン**で表示中の日にタスクを追加。スマホは表示モード（日 / 3日 / 週 / 2週 / 月）を PC とは別に記憶し、既定は日表示です
  - **タスクの追加・編集画面も TickTick 風のシンプル表示**になります。上段は丸い完了チェックと「9月2日(月) 10:00 - 11:00」の日時行だけ（タップすると日付・時間・実績の入力欄が開きます）。その下は大きめのタイトルとタグ、値の入っている項目だけが並び、空の項目（完了条件・詳細・プロジェクトなど）は「＋ 項目を追加」のメニューから選んで開きます（タグで必須になった欄が自動で開くのは今までどおり）。「削除」「ノートで開く」はアイコンボタンにまとまります

### ノートとの結びつき（v2.0 の新機能）

- タスクはノート内の **1ブロック**。タイムラインのブロックに本文の1行目がプレビュー表示されます
- **Ctrl/Cmd + クリック** … **作業メモ（ステップ・備考）をポップアップで表示**。ステップはその場でチェックでき、「編集」で作業メモのタブを開いたダイアログへ、「ノートで開く」でノートの該当ブロックへジャンプ。プロジェクトが結びついていればプロジェクトノートを直接開くアイコンも出ます（右クリックメニューの「作業メモを見る」でも同じ）
- **Ctrl/Cmd + ホバー** … 該当ブロックをポップアップでプレビュー（ページプレビュー機能）
- ノートを開いてタスクのブロックにカーソルを置くと、タイムライン側の対応するタスクが**光って同期**
- タスクにはブロックID（`^dtp-xxxx`）が付くので、`[[2026-08-18#^dtp-xxxx]]` で**タスク単位のリンク**が張れます
- **再スケジュール** … 時刻を決めていないタスクを、左サイドバーの「再スケジュール」タブに日付（オレンジの枠バッジ）付きで縦に一覧。表示中の週だけでなく、**過去30日以内に取り残された時刻なしタスクも（赤いバッジで）常に並ぶ**ので、週をまたいでも消えません。タイムラインへドラッグすると時刻が入ります（別の日の列に落とすと日付も移ります）
- **日付の変更** … 追加・編集ダイアログの「日付」欄でタスクの日付を変えられます（別の日のノートへブロックごと移動）。空にすると日付未定（Inbox）へ、日付未定のタスクに日付を入れるとその日のノートへ移ります
- **前日 / 翌日へ送る** … 本文ごとブロックを隣の日のノートへ移動
- **Inbox** … 日付を決めずに「とりあえず登録」するタスクの置き場（固定ノート `Timeline/Inbox.md`）。左サイドバーの「Inbox」タブに一覧され、日付の列へドラッグするとその日のノートへ移って時刻が入ります。逆に右クリック「Inbox へ戻す」で日付を外せます。パネルに出るのは**未完了かつプロジェクトに属さないタスクだけ**（完了したものやプロジェクト付きのものはノートには残り、プロジェクト付きはプロジェクトパネル側に表示されます）。例外として、結びついたプロジェクトがパネルに出ていない場合（完了済み・ノートが見つからない）は、タスクが行方不明にならないよう「▸ プロジェクト名」バッジ付きで Inbox に表示します
- **定期タスク** … 曜日と時刻を決めたルールを登録すると、今日以降の日を表示したときにその日のノートへ自動で書き込まれます。専用の管理画面で今後の予定の状態確認・回ごとの取り消し・回ごとの「個別詳細」の入力ができます
- **リマインド** … 今日の未完了タスクを、開始の N 分前に通知（既定 5 分前。タスクごとに変更可）
- **タイマー** … タスクとは無関係の単純なカウントダウン。ツールバー・ステータスバーに残り時間を表示し、終了したら通知＋ダイアログ（音は設定でオン/オフ）
- コマンド「カーソル位置の見出しをタスクにする」で、手書きの見出しもタスク化できます

## 保存先

ノートは既定で保管庫内の **`Timeline/`** フォルダに `YYYY-MM-DD.md` として保存されます（保管庫直下には置きません）。
フォルダ名・日付形式は設定で変更できます（デイリーノートのフォルダに合わせると同じノートを使えます）。

## 保存形式

### タスクブロック形式（v2.0 の既定）

タスク1件 = 「見出し + メタ行 + 自由な本文」。ファイル直下（または設定した親見出しの下）に並びます。

```markdown
---
date: 2026-08-18
---

今日のメモ。ここはタスクではないので触りません。

## 朝会
- [x] 09:00 - 10:00 ^dtp-k3f9a2
- 実績: 09:05 - 10:10
- 完了条件: 今日の担当が決まっている
- [x] 昨日の振り返り
- [ ] 今日の担当決め

議題: 進捗確認
決定: リリースは金曜

## 設計レビューの準備
- [ ] 10:30 - 12:00 ^dtp-9b2c44

- [ ] 資料の骨子
- [ ] 図を描く

## メールの棚卸し
- [ ] ^dtp-7ac105

（時刻なし = 未スケジュール。サイドバーの「再スケジュール」タブに表示されます）

## 振り返り
メタ行が無い見出しはタスクではありません。プラグインは触りません。
```

- **見出し行** = タスクのタイトル（レベルは設定で変更可・既定は `##`）
- **メタ行** = 見出し直下の `- [ ] HH:MM - HH:MM ^dtp-xxxx`。完了・時刻・ブロックID を持ちます
  - 時刻を省くと「未スケジュール」になります
  - `^dtp-xxxx` はプラグインが書き込むときに付ける Obsidian のブロックID です。タイトルや時刻を変えても対応が切れません
  - 手書きで `- 09:00 - 10:00` とだけ書いてもタスクとして認識されます（ID は次の保存時に付きます）
- **プロジェクト** = 本文中の `- プロジェクト: [[Timeline/Projects/環境構築]]` 行。大きなタスク（プロジェクトノート）への参照で、編集画面の「プロジェクト」欄と相互に反映。手書きの `[[リンク|別名]]` も読めます（ダイアログで変えない限り保持）
- **実績** = 本文中の `- 実績: HH:MM - HH:MM` 行。実際に作業した時間で、`/` で区切って複数区間を書けます（`- 実績: 09:15 - 09:45 / 13:00 - 13:30`）。編集画面の「実績」欄と相互に反映され、空にすると行ごと消えます。予定（メタ行）とは独立しているので予実の比較ができます
- **完了条件** = 本文中の `- 完了条件: …` 行（`完了条件：…` `**完了条件**: …` も可）。編集画面の「完了条件」欄と相互に反映され、空にすると行ごと消えます。無いときにダイアログで入力するとメタ行の直下に追加されます
- **チケット** = メタ行の `🎫redmine#65130`（ツール名は設定「チケット管理ツール」の名前。`🎫#65130` はツール省略 = 先頭のツール）。編集ダイアログの「チケット」欄と相互に反映
- **ふりかえり** = 本文中の `- ふりかえり: …` 行（`振り返り：…` も可）。編集画面の「ふりかえり」欄と相互に反映。完了時のポップアップから保存するとステップの後ろに追記されます
- **結果** = 本文中の `- 結果: …` 行。何がどこまで終わったかの記録で、完了時のポップアップと編集画面の「結果」欄に相互に反映。日報・週報の元データになります
- **残** = 本文中の `- 残: …` 行。完了にした後に残った作業。未チェックのステップが残るタスクを完了にすると、ここへ書き込むかを確認します
- **登録日** = 本文中の `- 登録日: YYYY-MM-DD` 行。Inbox に入れた日を自動で記録し、どれだけ滞留しているかを後から判定できます
- **ステップ** = メタ行（と完了条件行）の直後に続く、インデント無しのチェックリスト `- [ ] …`。空行までが1つのまとまりです。編集画面の「ステップ」と相互に反映され、並べ替えるとステップの下にぶら下がるインデント行も一緒に動きます。ノート側で追加・チェック・並べ替えしても反映されます
- **備考（本文）** = 完了条件・ステップ・ふりかえりの後ろに続く自由な Markdown。編集画面の「作業メモ」タブの「備考」欄と相互に反映されます（時刻やタイトルだけの変更では本文に触れません）
- ブロックの削除時、本文があるものは確認ダイアログを出します（設定でオフ可）
- 書き込みはブロック単位の部分置換です。ノート内の並び順は勝手に変えません（コマンド「タスクを時刻順に並べ替える」で明示的に並べ替え可能）

### タグで色分け

タスクの見出し・メタ行・本文のどこかに `#タグ` を書くと、設定「タグの色」で対応づけた色でタイムラインに表示されます。

```markdown
## 設計レビュー #work
- [ ] 10:30 - 12:00 ^dtp-9b2c44

## ジム #private/健康
- [ ] 19:00 - 20:00 ^dtp-7ac105
```

- **タスクの追加・編集ダイアログに、設定したタグが色付きボタンで並びます**。クリックで付け外しでき、選んだタグは見出しの末尾に `#タグ` として書き込まれます（設定に無いタグを手書きしてもそのまま残ります）
- 設定では「タグ」と「色」の組を複数登録でき、**上にあるものが優先**されます
- `work` は `#work` と `#work/xxx` の両方に一致します（大文字小文字は区別しません）
- 一致するタグが無いタスクはテーマのアクセント色のままです

### Inbox（日付を決めていないタスク）

「いつやるか決めていないが忘れたくない」タスクは Inbox に入れておけます。

- 左サイドバーの **Inbox タブ**（パネルは折りたたみ可）の ＋、またはコマンド「Inbox にタスクを追加」で登録
- Inbox の実体は設定「Inbox のノート」（既定 `Timeline/Inbox`）の Markdown。日付のノートと同じタスクブロック形式なので、本文にメモも書けます
- Inbox に入れたタスクには `- 登録日: YYYY-MM-DD` が自動で付きます（「Inbox へ戻す」でも更新）。いつから置いてあるか（滞留日数）が後から分かります
- チップを **タイムラインの日付の列へドラッグ** → その日のノートへブロックごと移動し、落とした時刻が入ります
- チップの右クリック → 「今日へ送る（未スケジュール）」「削除」など。編集ダイアログで日付を入れるとその日へ、日付を入れずに時刻だけ入れると今日に移ります
- タイムライン上のタスクの右クリック → **「Inbox へ戻す（日付を外す）」**
- タスクブロック形式のときだけ使えます

### 定期タスク

毎週決まった曜日・時刻に入れるタスクをルールとして登録できます。

- **専用の管理画面**で登録・編集します。タイムラインのツールバーの ⋮ メニューの「定期タスクを管理」、同名のコマンド、設定「定期タスク」→「定期タスクの管理画面を開く」のどれからでも開けます
  - 左にルールの一覧、右に選択中ルールの編集フォームと **今後の予定（4週間）** の一覧
  - 発生日ごとに **未反映 / 反映済み / 取り消し / 個別調整あり / 削除されています** の状態が出るので、「まだ入っていないのか、その日は取り消したのか」が一目で分かります
  - 各日の操作: **今すぐ入れる**（未反映の日に書き込む）・**この日は入れない / 取り消す**（その日だけやめる。書き込み済みならタスクごと削除）・**入れ直す**（取り消し・削除した日を戻す）
  - 行を開くと **個別詳細** — その回だけの詳細（本文）や時刻を書けます。まだ書き込まれていない日は書き込み時に反映され、書き込み済みの日はノートのタスクを直接書き換えます。時刻を個別に変えた回は、以後ルールを編集しても上書きされません
- ルールはタイトル（タグ付き可）・曜日（毎日 / 平日 / 週末のプリセットあり）・時刻（無しなら未スケジュールとして入る）・**共通の詳細**（毎回のタスクの本文に入るメモ）・**共通のステップ**（毎回のタスクに未チェックの `- [ ]` チェックリストとして入る。フォームでは1行に1ステップ。チェックは通常のタスクと同じく編集ダイアログやノートで）・有効/無効
- ほかに、コマンド「定期タスクを追加」、タスクの右クリック「**定期タスクとして登録…**」（タイトル・時刻・曜日に加え、タスクのステップも「共通のステップ」に入った状態で開きます）、設定「定期タスク」の一覧からも登録・編集できます
- タイムラインで **今日以降の日** を表示したとき、その日にまだ入れていないルールのタスクをノートに書き込みます（週表示なら来週分まで先に入ります）
- 一度入れた「日 × ルール」は記録するので、**消したタスクが勝手に復活することはありません**。タイムラインから削除した回は「取り消し」として記録され、管理画面と月表示（打ち消し線）で見分けられます
- **ルールを編集すると、すでにノートに入っている「今日以降」のタスクにも反映されます**（タイトル・時刻を書き換え。共通の詳細はその回の本文に、共通のステップはその回のステップに手を付けていない（チェック・追記していない）ときだけ書き換えます。完了状態・実績・個別調整した回には触れません）。反映結果は**書き換える対象が無かったときも含めて毎回通知**に出ます
  - 曜日を外した場合、その曜日の書き込み済みタスクは**手つかずならタスクごと削除**し、編集済み・完了済みなら残して件数を通知します
  - 過去分（昨日以前）は書き換えません
- 「定期タスクを自動で入れる」をオフにすると書き込みを止められます（管理画面の「今すぐ入れる」でのみ書き込まれます）

### メンバー（他の人の予定）

自分の予定とは**別のノート**に保存しつつ、同じカレンダーに重ねて見られます。

- 設定「メンバー（他の人の予定）」で **名前・色・保存フォルダ（既定 `<フォルダ>/Members/<名前>`）・リマインド対象か** を登録（目安 5 人程度）
- タイムラインの**ツールバーの「表示」メニューにメンバーの一覧**が並び、クリックで人ごとに表示/非表示（「全員を表示 / 自分だけにする」の一括項目も）。表示状態は記憶されます
- メンバーの予定は**グレーの背景に、左端の線だけその人の色**。ブロック先頭にその人の色の名前ラベルが付くので、自分の予定（タグ色で塗りつぶし）と一目で区別できます
- **追加**：編集ダイアログの「誰の予定か」で選ぶ（既定は自分）。**編集・ドラッグ・削除**も自分の予定と同じ操作で、書き込み先はその人のノート
- **持ち主の変更**：編集ダイアログの「誰の予定か」を変える、または右クリック「〇〇の予定にする」→ ブロックごとその人のノートへ移動
- リマインドは既定では自分の予定だけ。メンバーの設定でオンにするとその人の分も通知（「[田中] 打合せ」のように名前付き）
- 定期タスク・Inbox・エディタ連動は自分の予定のみ。タスクブロック形式のときだけ使えます

### リマインド

- Obsidian を開いている間、今日の未完了タスクについて **開始の N 分前**に通知します
- 通知の出し方は設定「通知の出し方」で選べます（既定は両方）
  - **OS の通知** … Windows / macOS のトースト（画面右下など）。Obsidian が最小化・背面でも届きます。初回に OS 側で許可を求められることがあります
  - **画面内のバナー** … Obsidian のウィンドウ右下に大きめのカードを、閉じるまで表示。「タイムラインを開く」「5分後にもう一度」ボタン付き
  - 設定の「テスト通知を出す」で見え方を確認できます
- N の既定は設定「既定のリマインド時刻」（既定 5 分前）。タスクの編集ダイアログの「リマインド」で **既定 / しない / 開始時刻 / 1〜60 分前** を個別に選べます
- 個別指定はメタ行に `🔔10`（10分前）/ `🔔off`（しない）として保存されます

```markdown
## 朝会
- [ ] 09:00 - 10:00 🔔10 ^dtp-k3f9a2
```

- 通知時刻を 2 分以上過ぎていた場合（Obsidian を閉じていたなど）は追いかけて通知しません

### タイマー

- ツールバーの ⋮ メニューの「タイマー…」、またはコマンド「タイマーを開始 / 操作」「タイマー: 5分/10分/15分/25分/30分/60分」
- ダイアログでプリセット（1〜90分）を選ぶか分数を入力（小数可）。ラベルも付けられます
- 動作中はツールバーとステータスバーに残り時間を表示。クリックで **+1分 / +5分 / 停止**
- 終了すると通知（OS 通知 / 画面内バナー。「もう一度」ボタン付き）とダイアログを出し（設定で音も鳴らせます）、ツールバーの表示が「終了」に変わります（クリックで消えます）

### リスト形式（旧形式・1.x 互換）

設定「タスクの形式」で従来の形式にも切り替えられます。

```markdown
## タイムスケジュール
- [ ] 09:00 - 10:00 朝会
    - 議題: 進捗確認
- [x] 10:30 - 12:00 開発作業
```

### 旧形式からの移行

ブロック形式で旧形式の予定が残っているノートを開くと、タイムライン上部に「変換」バナーが出ます。
コマンド「このノートの予定をタスクブロックに変換」でも実行できます。
1行 + ぶら下がりメモ → 「見出し + メタ行 + 本文」に展開され、予定以外の行は元の見出しの下に残ります。

### 2.0 からのアップグレードについて

- 表示する時間帯が旧既定値（0:00〜24:00）のままだった場合、7:00〜22:00 に切り替わります（変更していた場合はそのまま）
- フォルダが空欄（保管庫直下）だった場合、`Timeline` に切り替わります。既に保管庫直下に置いていたノートは、必要なら `Timeline/` へ移動してください

## インストール・更新（BRAT — スマホにおすすめ）

Android / iOS の Obsidian ではファイルを手でコピーするのが大変なので、[BRAT](https://github.com/TfTHacker/obsidian42-brat)（Beta Reviewers Auto-update Tool）を使うと、この GitHub リポジトリから直接インストール・更新できます（PC でも使えます）。

### 初回セットアップ

1. **設定 → コミュニティプラグイン** で「制限モード」をオフにし、「閲覧」から **BRAT** を検索してインストール・有効化する
2. **設定 → BRAT → Add beta plugin** を開く
3. リポジトリに `wineda/day-timeline-planner` と入力し、バージョンは **Latest version** のまま **Add plugin** を押す
4. プラグインがダウンロードされ、そのまま有効化される

### 更新するとき

- コマンドパレットで **「BRAT: Check for updates to all beta plugins and UPDATE」** を実行すると、最新リリースに更新されます
- BRAT の設定で **「Auto-update plugins at startup」** をオンにすると、Obsidian の起動時に自動で更新されます

新しいバージョンは、`master` ブランチにバージョン更新が入ると GitHub Actions が自動で [Releases](https://github.com/wineda/day-timeline-planner/releases) を作成し、BRAT がそれを拾います。

## インストール（手動）

1. [Releases](https://github.com/wineda/day-timeline-planner/releases) か `app/dist/` から `main.js` / `manifest.json` / `styles.css` の3つを入手する
2. 保管庫（Vault）の `.obsidian/plugins/` の中に `day-timeline-planner` というフォルダを作り、そこへ3つのファイルを入れる
3. Obsidian の **設定 → コミュニティプラグイン** で「制限モード」をオフにし、一覧を再読み込みして **Day Timeline Planner** をオンにする

| ツールバーの「表示」メニュー → 予定 / 予実 / 実績 | 予定バーだけ / 左に予定・右に実績 / 実績バーだけ、を切替 |
| 週表示の曜日ヘッダーをクリック | その日の日表示へ |
| 日付ヘッダーの日付（「木 3」）をクリック | 設定「日報のフォルダ」（既定 `daily`）にあるその日の**日報ノート**をポップアップで表示（左右スワイプ / ◀ ▶ / ← → で前後の日へ。ノートで開く・コピー。無い日はタスクの集計） |
| 空き時間をクリック / ドラッグ | タスクを追加 |
| タスクをクリック | 編集（タイトル・完了条件・ステップ・詳細・ふりかえり・タグ・チケット・時間・実績・リマインド・完了）／削除 |
| 編集画面の「実績」欄 | 実際に作業した時間を記録（`10:05 - 11:20 / 13:00 - 13:30` のように複数区間可。コピーボタンで予定を転記） |
| 編集画面の「プロジェクト」欄 / ブロックの「▸ プロジェクト名」バッジ | タスクをプロジェクト（大きなタスク）に入れる・新規作成する / プロジェクトノートを開く |
| サイドバーの「プロジェクト」タブ | 進行中の一覧＋進捗＋期日・チケット（予実の合計は件数へのホバーで表示）。ヘッダーの ⋮ メニューに新規作成・すべて展開 / 閉じる・フラット表示・完了済みを隠す・ノートのタスク一覧を更新をまとめています。クリックで展開して子タスクへジャンプ（ドキュメントのチップもここに並ぶ）、ドラッグでタイムラインに子タスクを作成、行の右クリックメニューからノートを開く・日付を決めずに Inbox へ子タスクを登録・プロジェクトを完了に |
| サイドバーの右端をドラッグ | Inbox・プロジェクトのパネルの幅を変更 |
| タスクを右クリック →「翌日へ持ち越す（記録を残す）」 | 今日のブロックを `[>]` で閉じて記録を残し、残ステップを引き継いだ続きのブロックを翌日（未スケジュール）に作成。「当日内で続きを作る」（同じ日のノートに続きを作る）・「Inbox へ持ち越す」も可 |
| タスクを右クリック →「実績の計測を開始」 | ストップウォッチで計測開始。ツールバーの ⏺ チップをクリックで終了して実績に追記（右クリックで「記録せずにやめる」） |
| タスクを完了にする | 実績が空なら「予定の開始 〜 今」で実績を自動記録（他タスクの実績と重なる時間帯は除く。設定でオフ可）。未チェックのステップが残っていれば「残: に記録して完了 / 翌日へ持ち越す / そのまま完了」を確認。タグで必須の欄が空なら「完了の記録」ポップアップ（結果・原因・判断・回答など空の欄だけ。実績の確認・修正も） |
| 実績バーをドラッグ / 下端をドラッグ（予実・実績表示） | 実績の時間帯を移動 / 終了時刻を変更 |
| ブロックの #番号 バッジをクリック / 右クリック「チケット #… を開く」 | チケットをブラウザで開く |
| 15分以上のタスクを完了にする | 結果かふりかえりが空ならポップアップで入力を促す（「あとで」でスキップ。Ctrl+Enter で保存） |
| 編集画面のステップ | ⋮⋮ をドラッグで並べ替え（Alt+↑↓ でも可）、Enter で次を追加、空欄で Backspace で削除、✕ で削除 |
| タスクを **Ctrl/Cmd + クリック** | 作業メモ（ステップ・備考）をポップアップで表示。ステップはその場でチェック可。「ノートで開く」でブロックへジャンプ |
| タスクを **Ctrl/Cmd + ホバー** | ブロックをプレビュー |
| プロジェクト名（パネル・ブロックの「▸」バッジ・Inbox のバッジ）を **Ctrl/Cmd + クリック** | プロジェクトノートをプレビュー（通常より大きなポップアップ） |
| タスクをドラッグ / 下端をドラッグ | 移動（週表示では別の日へも） / 終了時刻を変更 |
| 右クリック | 編集・完了・ノートで開く・チケットを開く・時刻を外す・前日 / 翌日へ送る・〇〇の予定にする・Inbox へ戻す・定期タスクとして登録・削除 |
| Inbox パネルの ＋ / チップをドラッグ | Inbox に登録 / その日へ移して時刻を割り当て |
| サイドバーの「再スケジュール」タブのタスクをドラッグしてタイムラインへ | 時刻を決めていないタスクに時刻を割り当て |
| ツールバーの ＋ | タスクを追加（再スケジュールタブの ＋ は時刻なしで追加） |
| ツールバーの ⋮ メニューの「ノートを開く」 | その日のノートを開く（無ければ作成） |
| ◀ ▶ / 今日 / 日付クリック / ← → キー | 日付を移動（週表示では1週間ずつ） |

時刻の入力欄は `9:00` `0930` `9` `２１：３０`（全角）などにも対応。編集ダイアログの時計ボタンで時刻を外して未スケジュールにできます。**モバイルでは時刻の欄をタップすると OS の時刻ピッカーが開きます**（キーボードで打つ必要はありません。ピッカーで選べない「24:00 終了」は、終了を 0:00 にすると「翌0時」として扱われます）。

編集ダイアログでの変更は自動で保存されます（保存ボタンは無く、「閉じる」・Enter・Esc で閉じるだけ。ボタン行の左に保存状態が表示されます）。ただし「誰の予定か」の変更と、Inbox のタスクに時刻を入れて今日へ移す操作は、ノートをまたぐ移動になるためダイアログを閉じたときに反映されます。

ダイアログはよく使う順（タイトル＋完了 → 時間・実績 → プロジェクト → タグ → ステップ）に並び、**値が空の任意項目（完了条件・詳細・ふりかえり・チケット・リマインド・誰の予定かなど）は隠れています**。下部の「＋ 完了条件」などのチップをクリックすると欄が開きます（値が入っている項目は最初から表示）。各項目の説明は行にマウスを乗せるとツールチップで出ます。ふりかえり欄は編集時のみ表示されます。スマホ・タブレットではチップの羅列の代わりに「＋ 項目を追加」ボタン1つにまとまり、メニューから選んで開きます（タグの候補フィールドが先頭）。日付・時間・実績も上段の日時行をタップしたときだけ開きます。

## 設定

| 項目 | 内容 |
| --- | --- |
| フォルダ | ノートを置くフォルダ（既定 `Timeline`。空欄にはできず、保管庫直下には置きません）。デイリーノートのフォルダに合わせると同じノートを使えます |
| ファイル名の日付形式 | Moment.js 形式（例 `YYYY-MM-DD`。`YYYY/MM/DD` のようにサブフォルダも可） |
| 新規ノートのテンプレート | ノートが無いときに使うテンプレート（`{{date}}` `{{date:FORMAT}}` `{{title}}` `{{time}}` を置換） |
| タスクの形式 | タスクブロック（既定）／リスト（旧形式） |
| タスクの見出しレベル | タスクとみなす見出しレベル（既定 `##`） |
| タスクを置く場所 | 空欄 = ファイル直下。「## 今日のタスク」のように親見出しを指定可 |
| 新しいタスクの挿入位置 | 時刻順の位置／末尾 |
| 本文があるタスクの削除を確認 | 確認ダイアログのオン／オフ |
| 削除したタスクの記録を残す | タスクを削除したとき `<フォルダ>/Log.md` に日時・タイトル・元のノートを1行で記録（既定オン） |
| メタ行にもタイトルを書く | `- [ ] 09:00 - 10:00 朝会 ^dtp-xxx` の形式にして他プラグイン（Tasks / Day Planner）からも見えるように |
| 旧形式の見出し | リスト形式で使う見出し。移行元にもなります |
| チェックボックス形式で保存 | オフにすると `- 09:00 - 10:00` で保存 |
| 既定の表示 | 開いたときの表示（週（既定）/ 2週間 / 3日 / 日 / 月） |
| 週の始まり | 週表示の左端の曜日（既定: 日曜日） |
| 表示する時間帯 / 1時間の高さ / スナップ間隔 / 新しい予定の長さ | タイムラインの表示・操作（時間帯の既定は 7:00〜22:00） |
| タグの色 | `#タグ` → 色 の対応を並べる。上が優先。「追加」で行を増やし、ゴミ箱で削除 |
| 定期タスク | 管理画面を開くボタン、自動で入れるかのオン/オフ、ルールの一覧（追加・編集・有効/無効・削除） |
| Inbox | パネルの表示オン/オフと、Inbox のノートのパス（既定 `Timeline/Inbox`） |
| 通知 | タスクのリマインドのオン/オフ、既定の「N分前」、通知の出し方（OS 通知 / 画面内バナー / 両方）、テスト通知、音を鳴らすか |
| メンバー | 他の人の予定。名前・色・フォルダ・リマインド対象を登録。表示/非表示はツールバーの「表示」メニューで切替 |
| チケット管理ツール | 名前と URL テンプレートの組を登録（例 `redmine` / `https://redmine.example.com/issues/{id}`）。{id} が番号に置き換わります |
| 現在時刻のラインを表示 / 再スケジュール欄を表示 | 表示のオン／オフ |
| 完了にしたとき実績を自動で記録 | 実績が空のタスクを完了にすると「予定の開始 〜 今」で実績を記録（完了が予定とかけ離れた時刻なら予定どおりとして記録）。同じ日の他タスクの実績と重なる時間帯は除く。既定オン |
| プロジェクトのフォルダ | プロジェクト（大きなタスク）のノートを置く場所。空欄 = `<フォルダ>/Projects` |
| プロジェクトのテンプレート | プロジェクトを新規作成するときのテンプレートノート（任意。空欄 = 最小の雛形）。`{{name}}` `{{date}}` `{{time}}` `{{group}}` を置換。「テンプレートを作成」でサンプルを書き出せます |
| プロジェクトのパネルを表示 | Inbox の下のプロジェクト一覧のオン／オフ |
| ビューを開く場所 | メインエリア（タブ）／右サイドバー／左サイドバー |

## ソースからビルドする

```bash
npm install
npm run build      # main.js を生成
npm run dev        # 変更を監視して自動ビルド
```

`src/` の構成:

- `main.ts` … プラグイン本体（ビューの登録、コマンド、設定）
- `model.ts` … ビューが扱うタスクの型と、保存形式を差し替えるインターフェース
- `markdown/`
  - `id.ts` … ブロックID（`^dtp-xxxx`）の生成・抽出
  - `blocks.ts` … タスクブロック形式の解析・行の生成（Obsidian 非依存）
  - `edit.ts` … 追加・更新・削除・移動・並べ替え。毎回パースし直して ID で照合し、行単位で部分置換する
  - `legacy.ts` … 旧リスト形式の解析・生成（1.x 互換）
  - `migrate.ts` … 旧形式 → ブロック形式への変換
- `store.ts` … 日付 → ノートの解決と読み書き（`BlockTaskStore` / `ListTaskStore` / Inbox 用の `InboxStore` / メンバー用の `MemberStore`）
- `view.ts` … タイムライン表示、再スケジュール欄、クリック／ドラッグ操作、エディタ連動
- `modal.ts` … タスクの追加・編集ダイアログ、削除確認
- `layout.ts` … 重なったタスクを横に並べる計算
- `recurring.ts` … 定期タスクのルール・発生日ごとの記録（取り消し・個別調整）と、その日のノートへの反映
- `recurring-view.ts` … 定期タスクの管理画面（ルール一覧・今後の予定の状態・個別詳細の編集）
- `notify.ts` … タイマー（カウントダウン・ステータスバー・ダイアログ）とリマインド（開始 N 分前の通知）
- `settings.ts` … 設定と設定画面
- `util.ts` … 時刻・日付のユーティリティ

## 制限事項

- 日をまたぐタスク（例 23:00〜1:00）には対応していません（同じ日の 24:00 までとして扱います）
- ブロック形式のタスクは、コードブロック内の見出しや frontmatter を除く、設定したレベルの見出しだけを対象にします
- モバイルのドラッグ操作は**長押ししてから**始めます（誤操作を避けるため。すぐ動かすとスクロール・横スワイプになります）
- 月表示ではドラッグ操作はできません（クリックで編集・追加。モバイルはタップでその日の日表示へ）。月表示中は定期タスクの自動反映を行いません（6週分のノートを一度に作らないため）
- 週表示で列をまたいでドラッグしたときは「ブロックを移動 → 時刻を更新」の2段階で書き込みます（旧リスト形式でも同様）
