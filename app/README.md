# Day Timeline Planner（Obsidian プラグイン）

1日のタイムスケジュールを、Google カレンダーの「日」表示のように **時間帯をクリック／ドラッグして組み立てられる** Obsidian プラグインです。

v2.0 から、タスクは **デイリーノート内の Markdown ブロック（見出し + 本文）** として保存されます。
「1タスク = ノート内の1ブロック」なので、タイムラインで組んだ予定の下にそのままメモ・議事録・チェックリストを書け、一日にすることを1枚の Markdown にまとめられます。プラグインを外してもデータはただの Markdown として残ります。

## できること

### タイムライン

- **日 / 3日 / 週 / 月 表示** … 既定は週表示（日曜始まり・7日分を横に並べる）。ヘッダーの「日 / 3日 / 週 / 月」でいつでも切替。曜日ヘッダーや月のマスの日付をクリックするとその日の日表示へ
- **月表示** … カレンダーのマスに各日のタスクを時刻順に並べます（タグの色つき・時刻なしは破線）。タスクをクリックで編集、空きをクリック / ＋ で追加、右クリックでメニュー。まだノートに入っていない将来の定期タスクは薄く表示
- **タイムライン表示** … 時間軸は既定で 7:00〜22:00（表示する時間帯・1時間の高さ・週の始まりは設定で変更可）
- **表示する時間の幅（ズーム）** … ヘッダーの「4h / 8h / 12h / 標準」で、一度に見える時間の幅を切替（選択は記憶されます）。30分単位で作業する日は 4h にすると細かいタスクが見やすくなります。「標準」は設定の「1時間あたりの高さ」に従います
- **予定と実績（予実管理）** … タスクの「予定」とは別に、実際に作業した時間を「実績」として記録できます。編集ダイアログの「実績」欄（`10:05 - 11:20 / 13:00 - 13:30` のように複数区間可、コピーボタンで予定を転記）で入力し、ノートには `- 実績: …` 行として保存（相互反映）。ヘッダーの「予定 / 予実 / 実績」で表示を切替 — 予実では各日の列を左右に分け、**左＝予定（枠）、右＝実績（塗り）**で並べます。日付ヘッダーには「予 6:00 実 6:45 (+0:45)」のように日ごとの予実合計と差異を表示
- **タグで色分け** … タスクに書いた `#タグ` に応じてブロックの色を変えられます（設定「タグの色」）。タイムライン上ではタグの文字は出さず、色だけで示します
- **完了条件** … 編集画面の「完了条件」欄がノートの `- 完了条件: …` 行と相互に反映
- **ステップ** … タスクを小さく分けたチェックリスト。編集画面でチェック・追加・削除・**ドラッグで並べ替え**でき、ノートの `- [ ] …` 行と相互に反映
- **メンバー（他の人の予定）** … 設定でメンバー（名前・色）を登録すると、その人の予定を**別フォルダのノート**（`Timeline/Members/<名前>/YYYY-MM-DD.md`）に保存しつつ、自分のカレンダーに重ねて表示（グレー背景＋左端がその人の色）。ヘッダーのチップで人ごとに表示/非表示、編集ダイアログの「誰の予定か」で持ち主を選択・変更
- **チケット連携** … Redmine / Gitea / Backlog などのチケット番号をタスクに付けられます。タイムラインのブロックに `#65130` バッジが表示され、クリックでブラウザで開きます
- **詳細** … 自由なメモ（Markdown・複数行）。編集画面のテキストエリアがノートのブロック本文と相互に反映
- **ふりかえり** … 作業の改善を残す欄。**15分以上のタスクを完了にしたとき、ふりかえりが空ならポップアップで入力を促します**。ノートの `- ふりかえり: …` 行と相互に反映
- **クリックで追加** … 空いている時間をクリック → 既定の長さのタスクを作成
- **ドラッグで範囲を指定して追加** … 空いている時間をドラッグ → その範囲でタスクを作成
- **タスクをドラッグして移動**（週表示では別の日の列へドラッグして日付も移動）、**下端をドラッグして長さを変更**
- **クリックで編集**（タイトル・開始・終了・完了）、右クリックメニューで完了／削除／翌日へ送るなど
- 重なったタスクは横に並べて表示、現在時刻の赤いラインを表示
- ヘッダーの ◀ ▶ / 「今日」/ 日付クリックでカレンダーから選択（← → キーでも移動。3日表示は3日、週表示は1週間、月表示は1か月ずつ）

### ノートとの結びつき（v2.0 の新機能）

- タスクはノート内の **1ブロック**。タイムラインのブロックに本文の1行目がプレビュー表示されます
- **Ctrl/Cmd + クリック** … ノートの該当ブロックへジャンプ
- **Ctrl/Cmd + ホバー** … 該当ブロックをポップアップでプレビュー（ページプレビュー機能）
- ノートを開いてタスクのブロックにカーソルを置くと、タイムライン側の対応するタスクが**光って同期**
- タスクにはブロックID（`^dtp-xxxx`）が付くので、`[[2026-08-18#^dtp-xxxx]]` で**タスク単位のリンク**が張れます
- **未スケジュールのトレイ** … 時刻を決めていないタスクを上部に一覧。タイムラインへドラッグすると時刻が入ります（週表示では別の日の列に落とすと日付も移ります）
- **前日 / 翌日へ送る** … 本文ごとブロックを隣の日のノートへ移動
- **Inbox** … 日付を決めずに「とりあえず登録」するタスクの置き場（固定ノート `Timeline/Inbox.md`）。タイムライン上部のパネルに一覧され、日付の列へドラッグするとその日のノートへ移って時刻が入ります。逆に右クリック「Inbox へ戻す」で日付を外せます
- **定期タスク** … 曜日と時刻を決めたルールを登録すると、今日以降の日を表示したときにその日のノートへ自動で書き込まれます
- **リマインド** … 今日の未完了タスクを、開始の N 分前に通知（既定 5 分前。タスクごとに変更可）
- **タイマー** … タスクとは無関係の単純なカウントダウン。ヘッダー・ステータスバーに残り時間を表示し、終了したら通知＋ダイアログ（音は設定でオン/オフ）
- コマンド「カーソル位置の見出しをタスクにする」で、手書きの見出しもタスク化できます

## 保存先

ノートは既定で保管庫内の **`Timeline/`** フォルダに `YYYY-MM-DD.md` として保存されます（保管庫直下には置きません）。
フォルダ名・日付形式は設定で変更できます（デイリーノートのフォルダに合わせると同じノートを使えます）。

## 保存形式

### タスクブロック形式（v2.0 の既定）

タスク1件 = 「見出し + メタ行 + 自由な本文」。ファイル直下（または設定した親見出しの下）に並びます。

```markdown
---
date: 2026-08-18
---

今日のメモ。ここはタスクではないので触りません。

## 朝会
- [x] 09:00 - 10:00 ^dtp-k3f9a2
- 実績: 09:05 - 10:10
- 完了条件: 今日の担当が決まっている
- [x] 昨日の振り返り
- [ ] 今日の担当決め

議題: 進捗確認
決定: リリースは金曜

## 設計レビューの準備
- [ ] 10:30 - 12:00 ^dtp-9b2c44

- [ ] 資料の骨子
- [ ] 図を描く

## メールの棚卸し
- [ ] ^dtp-7ac105

（時刻なし = 未スケジュール。トレイに表示されます）

## 振り返り
メタ行が無い見出しはタスクではありません。プラグインは触りません。
```

- **見出し行** = タスクのタイトル（レベルは設定で変更可・既定は `##`）
- **メタ行** = 見出し直下の `- [ ] HH:MM - HH:MM ^dtp-xxxx`。完了・時刻・ブロックID を持ちます
  - 時刻を省くと「未スケジュール」になります
  - `^dtp-xxxx` はプラグインが書き込むときに付ける Obsidian のブロックID です。タイトルや時刻を変えても対応が切れません
  - 手書きで `- 09:00 - 10:00` とだけ書いてもタスクとして認識されます（ID は次の保存時に付きます）
- **実績** = 本文中の `- 実績: HH:MM - HH:MM` 行。実際に作業した時間で、`/` で区切って複数区間を書けます（`- 実績: 09:15 - 09:45 / 13:00 - 13:30`）。編集画面の「実績」欄と相互に反映され、空にすると行ごと消えます。予定（メタ行）とは独立しているので予実の比較ができます
- **完了条件** = 本文中の `- 完了条件: …` 行（`完了条件：…` `**完了条件**: …` も可）。編集画面の「完了条件」欄と相互に反映され、空にすると行ごと消えます。無いときにダイアログで入力するとメタ行の直下に追加されます
- **チケット** = メタ行の `🎫redmine#65130`（ツール名は設定「チケット管理ツール」の名前。`🎫#65130` はツール省略 = 先頭のツール）。編集ダイアログの「チケット」欄と相互に反映
- **ふりかえり** = 本文中の `- ふりかえり: …` 行（`振り返り：…` も可）。編集画面の「ふりかえり」欄と相互に反映。完了時のポップアップから保存するとステップの後ろに追記されます
- **ステップ** = メタ行（と完了条件行）の直後に続く、インデント無しのチェックリスト `- [ ] …`。空行までが1つのまとまりです。編集画面の「ステップ」と相互に反映され、並べ替えるとステップの下にぶら下がるインデント行も一緒に動きます。ノート側で追加・チェック・並べ替えしても反映されます
- **詳細（本文）** = 完了条件・ステップ・ふりかえりの後ろに続く自由な Markdown。編集画面の「詳細」欄と相互に反映されます（時刻やタイトルだけの変更では本文に触れません）
- ブロックの削除時、本文があるものは確認ダイアログを出します（設定でオフ可）
- 書き込みはブロック単位の部分置換です。ノート内の並び順は勝手に変えません（コマンド「タスクを時刻順に並べ替える」で明示的に並べ替え可能）

### タグで色分け

タスクの見出し・メタ行・本文のどこかに `#タグ` を書くと、設定「タグの色」で対応づけた色でタイムラインに表示されます。

```markdown
## 設計レビュー #work
- [ ] 10:30 - 12:00 ^dtp-9b2c44

## ジム #private/健康
- [ ] 19:00 - 20:00 ^dtp-7ac105
```

- **タスクの追加・編集ダイアログに、設定したタグが色付きボタンで並びます**。クリックで付け外しでき、選んだタグは見出しの末尾に `#タグ` として書き込まれます（設定に無いタグを手書きしてもそのまま残ります）
- 設定では「タグ」と「色」の組を複数登録でき、**上にあるものが優先**されます
- `work` は `#work` と `#work/xxx` の両方に一致します（大文字小文字は区別しません）
- 一致するタグが無いタスクはテーマのアクセント色のままです

### Inbox（日付を決めていないタスク）

「いつやるか決めていないが忘れたくない」タスクは Inbox に入れておけます。

- タイムライン上部の **Inbox パネル**（▸ で折りたたみ可）の ＋、またはコマンド「Inbox にタスクを追加」で登録
- Inbox の実体は設定「Inbox のノート」（既定 `Timeline/Inbox`）の Markdown。日付のノートと同じタスクブロック形式なので、本文にメモも書けます
- チップを **タイムラインの日付の列へドラッグ** → その日のノートへブロックごと移動し、落とした時刻が入ります
- チップの右クリック → 「今日へ送る（未スケジュール）」「削除」など。編集ダイアログで時刻を入れると今日に移ります
- タイムライン上のタスクの右クリック → **「Inbox へ戻す（日付を外す）」**
- タスクブロック形式のときだけ使えます

### 定期タスク

毎週決まった曜日・時刻に入れるタスクをルールとして登録できます。

- **タイムラインのヘッダーの ⟳（繰り返し）アイコン**から一覧ダイアログを開けます（追加・編集・有効/無効・削除）。設定画面を開く必要はありません
- ほかに、設定「定期タスク」→「追加」、コマンド「定期タスクを管理」「定期タスクを追加」、タスクの右クリック「**定期タスクとして登録…**」（タイトル・時刻・曜日が入った状態で開きます）からも登録できます
- ルールはタイトル（タグ付き可）・曜日（毎日 / 平日 / 週末のプリセットあり）・時刻（無しなら未スケジュールとして入る）・有効/無効
- タイムラインで **今日以降の日** を表示したとき、その日にまだ入れていないルールのタスクをノートに書き込みます（週表示なら来週分まで先に入ります）
- 一度入れた「日 × ルール」は記録するので、**消したタスクが勝手に復活することはありません**
- **ルールを編集すると、すでにノートに入っている「今日以降」のタスクにも反映されます**（タイトルと時刻を書き換え。本文・完了状態・手で動かした日付には触れません）。反映した件数が通知に出ます
  - 曜日を変えた場合、新しい曜日は次から入りますが、すでに入っている日からは自動では消しません（不要なら手で削除してください）
  - 過去分（昨日以前）は書き換えません
- 「定期タスクを自動で入れる」をオフにすると書き込みを止められます

### メンバー（他の人の予定）

自分の予定とは**別のノート**に保存しつつ、同じカレンダーに重ねて見られます。

- 設定「メンバー（他の人の予定）」で **名前・色・保存フォルダ（既定 `<フォルダ>/Members/<名前>`）・リマインド対象か** を登録（目安 5 人程度）
- タイムラインの**ヘッダーに色付きチップ**が並び、クリックで人ごとに表示/非表示（「全員 / 自分だけ」の一括ボタンも）。表示状態は記憶されます
- メンバーの予定は**グレーの背景に、左端の線だけその人の色**。ブロック先頭にその人の色の名前ラベルが付くので、自分の予定（タグ色で塗りつぶし）と一目で区別できます
- **追加**：編集ダイアログの「誰の予定か」で選ぶ（既定は自分）。**編集・ドラッグ・削除**も自分の予定と同じ操作で、書き込み先はその人のノート
- **持ち主の変更**：編集ダイアログの「誰の予定か」を変える、または右クリック「〇〇の予定にする」→ ブロックごとその人のノートへ移動
- リマインドは既定では自分の予定だけ。メンバーの設定でオンにするとその人の分も通知（「[田中] 打合せ」のように名前付き）
- 定期タスク・Inbox・エディタ連動は自分の予定のみ。タスクブロック形式のときだけ使えます

### リマインド

- Obsidian を開いている間、今日の未完了タスクについて **開始の N 分前**に通知します
- 通知の出し方は設定「通知の出し方」で選べます（既定は両方）
  - **OS の通知** … Windows / macOS のトースト（画面右下など）。Obsidian が最小化・背面でも届きます。初回に OS 側で許可を求められることがあります
  - **画面内のバナー** … Obsidian のウィンドウ右下に大きめのカードを、閉じるまで表示。「タイムラインを開く」「5分後にもう一度」ボタン付き
  - 設定の「テスト通知を出す」で見え方を確認できます
- N の既定は設定「既定のリマインド時刻」（既定 5 分前）。タスクの編集ダイアログの「リマインド」で **既定 / しない / 開始時刻 / 1〜60 分前** を個別に選べます
- 個別指定はメタ行に `🔔10`（10分前）/ `🔔off`（しない）として保存されます

```markdown
## 朝会
- [ ] 09:00 - 10:00 🔔10 ^dtp-k3f9a2
```

- 通知時刻を 2 分以上過ぎていた場合（Obsidian を閉じていたなど）は追いかけて通知しません

### タイマー

- ヘッダーの ⏱ ボタン、またはコマンド「タイマーを開始 / 操作」「タイマー: 5分/10分/15分/25分/30分/60分」
- ダイアログでプリセット（1〜90分）を選ぶか分数を入力（小数可）。ラベルも付けられます
- 動作中はヘッダーとステータスバーに残り時間を表示。クリックで **+1分 / +5分 / 停止**
- 終了すると通知（OS 通知 / 画面内バナー。「もう一度」ボタン付き）とダイアログを出し（設定で音も鳴らせます）、ヘッダーの表示が「終了」に変わります（クリックで消えます）

### リスト形式（旧形式・1.x 互換）

設定「タスクの形式」で従来の形式にも切り替えられます。

```markdown
## タイムスケジュール
- [ ] 09:00 - 10:00 朝会
    - 議題: 進捗確認
- [x] 10:30 - 12:00 開発作業
```

### 旧形式からの移行

ブロック形式で旧形式の予定が残っているノートを開くと、タイムライン上部に「変換」バナーが出ます。
コマンド「このノートの予定をタスクブロックに変換」でも実行できます。
1行 + ぶら下がりメモ → 「見出し + メタ行 + 本文」に展開され、予定以外の行は元の見出しの下に残ります。

### 2.0 からのアップグレードについて

- 表示する時間帯が旧既定値（0:00〜24:00）のままだった場合、7:00〜22:00 に切り替わります（変更していた場合はそのまま）
- フォルダが空欄（保管庫直下）だった場合、`Timeline` に切り替わります。既に保管庫直下に置いていたノートは、必要なら `Timeline/` へ移動してください

## インストール（手動）

1. 保管庫（Vault）の `.obsidian/plugins/` の中に `day-timeline-planner` というフォルダを作る
2. そのフォルダに `main.js` / `manifest.json` / `styles.css` の3つを入れる
3. Obsidian の **設定 → コミュニティプラグイン** で「制限モード」をオフにし、一覧を再読み込みして **Day Timeline Planner** をオンにする

| ブロックの #番号 バッジをクリック / 右クリック「チケット #… を開く」 | チケットをブラウザで開く |
| 15分以上のタスクを完了にする | ふりかえりが空ならポップアップで入力を促す（「あとで」でスキップ。Ctrl+Enter で保存） |
| 編集画面のステップ | ⋮⋮ をドラッグで並べ替え（Alt+↑↓ でも可）、Enter で次を追加、空欄で Backspace で削除、✕ で削除 |
| タスクを **Ctrl/Cmd + クリック** | ノートの該当ブロックへジャンプ |
| タスクを **Ctrl/Cmd + ホバー** | ブロックをプレビュー |
| タスクをドラッグ / 下端をドラッグ | 移動（週表示では別の日へも） / 終了時刻を変更 |
| 右クリック | 編集・完了・ノートで開く・チケットを開く・時刻を外す・前日 / 翌日へ送る・〇〇の予定にする・Inbox へ戻す・定期タスクとして登録・削除 |
| Inbox パネルの ＋ / チップをドラッグ | Inbox に登録 / その日へ移して時刻を割り当て |
| トレイのチップをドラッグしてタイムラインへ | 未スケジュールのタスクに時刻を割り当て |
| ヘッダーの ＋ | タスクを追加（トレイの ＋ は未スケジュールで追加） |
| ヘッダーのノートアイコン | その日のノートを開く（無ければ作成） |
| ◀ ▶ / 今日 / 日付クリック / ← → キー | 日付を移動（週表示では1週間ずつ） |

時刻の入力欄は `9:00` `0930` `9` `２１：３０`（全角）などにも対応。編集ダイアログの時計ボタンで時刻を外して未スケジュールにできます。

編集ダイアログでの変更は自動で保存されます（保存ボタンは無く、「閉じる」・Enter・Esc で閉じるだけ。ボタン行の左に保存状態が表示されます）。ただし「誰の予定か」の変更と、Inbox のタスクに時刻を入れて今日へ移す操作は、ノートをまたぐ移動になるためダイアログを閉じたときに反映されます。

## コマンド

- タイムスケジュールを開く
- 今日のスケジュールノートを開く
- タイムスケジュール: 前へ / 次へ / 今日へ（週表示では1週間ずつ動きます）
- タイムスケジュール: 日表示 / 週表示を切り替える（日 → 3日 → 週 → 月 の順に切替）
- Inbox にタスクを追加（日付を決めずに登録） / Inbox のノートを開く
- 定期タスクを管理 / 定期タスクを追加
- タイマーを開始 / 操作、タイマー: 5分 / 10分 / 15分 / 25分 / 30分 / 60分
- このノートの予定をタスクブロックに変換
- タイムスケジュール: タスクを時刻順に並べ替える
- カーソル位置の見出しをタスクにする

## 設定

| 項目 | 内容 |
| --- | --- |
| フォルダ | ノートを置くフォルダ（既定 `Timeline`。空欄にはできず、保管庫直下には置きません）。デイリーノートのフォルダに合わせると同じノートを使えます |
| ファイル名の日付形式 | Moment.js 形式（例 `YYYY-MM-DD`。`YYYY/MM/DD` のようにサブフォルダも可） |
| 新規ノートのテンプレート | ノートが無いときに使うテンプレート（`{{date}}` `{{date:FORMAT}}` `{{title}}` `{{time}}` を置換） |
| タスクの形式 | タスクブロック（既定）／リスト（旧形式） |
| タスクの見出しレベル | タスクとみなす見出しレベル（既定 `##`） |
| タスクを置く場所 | 空欄 = ファイル直下。「## 今日のタスク」のように親見出しを指定可 |
| 新しいタスクの挿入位置 | 時刻順の位置／末尾 |
| 本文があるタスクの削除を確認 | 確認ダイアログのオン／オフ |
| メタ行にもタイトルを書く | `- [ ] 09:00 - 10:00 朝会 ^dtp-xxx` の形式にして他プラグイン（Tasks / Day Planner）からも見えるように |
| 旧形式の見出し | リスト形式で使う見出し。移行元にもなります |
| チェックボックス形式で保存 | オフにすると `- 09:00 - 10:00` で保存 |
| 既定の表示 | 開いたときの表示（週（既定）/ 3日 / 日 / 月） |
| 週の始まり | 週表示の左端の曜日（既定: 日曜日） |
| 表示する時間帯 / 1時間の高さ / スナップ間隔 / 新しい予定の長さ | タイムラインの表示・操作（時間帯の既定は 7:00〜22:00） |
| タグの色 | `#タグ` → 色 の対応を並べる。上が優先。「追加」で行を増やし、ゴミ箱で削除 |
| 定期タスク | 自動で入れるかのオン/オフと、ルールの一覧（追加・編集・有効/無効・削除） |
| Inbox | パネルの表示オン/オフと、Inbox のノートのパス（既定 `Timeline/Inbox`） |
| 通知 | タスクのリマインドのオン/オフ、既定の「N分前」、通知の出し方（OS 通知 / 画面内バナー / 両方）、テスト通知、音を鳴らすか |

| チケット管理ツール | 名前と URL テンプレートの組を登録（例 `redmine` / `https://redmine.example.com/issues/{id}`）。{id} が番号に置き換わります |
| 現在時刻のラインを表示 / 未スケジュールのトレイを表示 | 表示のオン／オフ |
| ビューを開く場所 | メインエリア（タブ）／右サイドバー／左サイドバー |

## ソースからビルドする

```bash
npm install
npm run build      # main.js を生成
npm run dev        # 変更を監視して自動ビルド
```

`src/` の構成:

- `main.ts` … プラグイン本体（ビューの登録、コマンド、設定）
- `model.ts` … ビューが扱うタスクの型と、保存形式を差し替えるインターフェース
- `markdown/`
  - `id.ts` … ブロックID（`^dtp-xxxx`）の生成・抽出
  - `blocks.ts` … タスクブロック形式の解析・行の生成（Obsidian 非依存）
  - `edit.ts` … 追加・更新・削除・移動・並べ替え。毎回パースし直して ID で照合し、行単位で部分置換する
  - `legacy.ts` … 旧リスト形式の解析・生成（1.x 互換）
  - `migrate.ts` … 旧形式 → ブロック形式への変換
- `store.ts` … 日付 → ノートの解決と読み書き（`BlockTaskStore` / `ListTaskStore` / Inbox 用の `InboxStore` / メンバー用の `MemberStore`）
- `view.ts` … タイムライン表示、トレイ、クリック／ドラッグ操作、エディタ連動
- `modal.ts` … タスクの追加・編集ダイアログ、削除確認
- `layout.ts` … 重なったタスクを横に並べる計算
- `recurring.ts` … 定期タスクのルール編集ダイアログと、その日のノートへの反映
- `notify.ts` … タイマー（カウントダウン・ステータスバー・ダイアログ）とリマインド（開始 N 分前の通知）
- `settings.ts` … 設定と設定画面
- `util.ts` … 時刻・日付のユーティリティ

## 制限事項

- 日をまたぐタスク（例 23:00〜1:00）には対応していません（同じ日の 24:00 までとして扱います）
- ブロック形式のタスクは、コードブロック内の見出しや frontmatter を除く、設定したレベルの見出しだけを対象にします
- モバイルでは、タップで追加・編集はできますが、ドラッグ操作は環境によって効かない場合があります
- 月表示ではドラッグ操作はできません（クリックで編集・追加）。月表示中は定期タスクの自動反映を行いません（6週分のノートを一度に作らないため）
- 週表示で列をまたいでドラッグしたときは「ブロックを移動 → 時刻を更新」の2段階で書き込みます（旧リスト形式でも同様）
